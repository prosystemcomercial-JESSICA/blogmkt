# Frase de impacto

Só tipografia sobre branco com losangos nos cantos, feita para compartilhar e marcar alguém.

**Forneça:** uma frase curta e um convite, como "Marque quem precisa ler isso.".

**Use:** títulos em `azul-profundo` ou, na padaria, em `laranja-queimado`.

**Não faça:** não acrescente foto.
