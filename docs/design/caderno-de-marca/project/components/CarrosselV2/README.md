# Carrossel V2

Carrossel de 6 páginas com foto em destaque em todas as páginas, usado quando o assunto rende boas imagens.

**Forneça:** segmento, título e apoio da capa, 3 itens de conteúdo (título, apoio e foto), solução, pergunta final e fotos.

**Faça:** use V2 da capa à última página.

**Não faça:** não misture com páginas da V3.

Gerador: `outputs/criativos/modelos/carrossel/gerar-variacoes.js`. Estrutura página a página em Tipos de posts.
