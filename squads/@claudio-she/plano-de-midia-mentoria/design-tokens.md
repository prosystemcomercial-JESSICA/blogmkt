## Cores

| Token | Hex | Uso |
|---|---|---|
| --color-primary | #4A7AB8 | Header, títulos, badges, bordas de destaque |
| --color-primary-light | #7BA3D0 | Gradientes, hovers, variações |
| --color-primary-bg | rgba(74,122,184,0.08) | Fundos de seção (baixa opacidade) |
| --color-accent | #2E5A8F | CTAs, destaques, elementos de ação, hover de botões |
| --color-text | #1F2937 | Texto principal (cinza-azulado) |
| --color-muted | #6B7280 | Texto secundário, metadados |
| --color-border | #D1E0F0 | Bordas de cards e separadores |
| --color-bg-light | #F8FAFC | Fundo claro de seções |
| --color-white | #FFFFFF | Fundo limpo, texto sobre escuro |

## Tom Visual

Tom: corporativo profissional, acessível, orientado a resultados
Espaçamento: equilibrado (48px desktop / 24px mobile)
Estilo de card: com sombra suave + borda #D1E0F0
Border radius: 8px (botões/cards) | 12px (cards principais)

## Notas

- Cor primária #4A7AB8 extraída visualmente do wordmark "PROSYSTEM™" e ícone play do logotipo
- Cor de acento #2E5A8F é variação mais escura da primária — uso em hover e CTAs pesados
- Fontes exatas do site não acessíveis via CSS público — usar fallbacks Montserrat + Inter
- NÃO usar gradientes saturados, neon, ilustrações lúdicas ou paletas vibrantes — foge ao tom corporativo
