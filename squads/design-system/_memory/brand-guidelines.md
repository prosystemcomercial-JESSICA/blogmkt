# Brand Guidelines — ProSystem Sistemas
> Extraído de: Logotipo oficial (`_expxagents/_assets/logo.png`) + site https://prosystemnet.com
> Data de extração: 12/05/2026

## Identidade Visual

### Logotipo
- Wordmark "PROSYSTEM™" em letras maiúsculas, fonte sans-serif geométrica arredondada, na cor azul `#4A7AB8`
- Ícone circular azul à esquerda, com triângulo "play" branco no centro (sugere ação, movimento, sistema em execução)
- Tagline em itálico: "Desenvolvimento de Sistemas"
- Versões disponíveis:
  - `_expxagents/_assets/logo.png` — colorida (fundo claro)
  - `_expxagents/_assets/logo-branco.png` — versão para fundo escuro

## Paleta de Cores

| Cor | Hex | Significado |
|-----|-----|-------------|
| Azul ProSystem | `#4A7AB8` | Confiança, tecnologia, profissionalismo — cor primária |
| Azul escuro | `#2E5A8F` | Profundidade, estabilidade — hover e destaque |
| Cinza-azulado | `#1F2937` | Texto principal — legibilidade séria |
| Branco | `#FFFFFF` | Fundo, espaço de respiro |
| Cinza médio | `#6B7280` | Metadados, texto secundário |

## Tipografia
- **Títulos:** sans-serif geométrica (fallback: Montserrat) em pesos 600/700
- **Corpo:** sans-serif humanista de alta legibilidade (fallback: Inter) em peso 400/500
- Fontes exatas do site `não identificadas` — usar fallbacks acima

## Estilo Visual dos Criativos

### Composição
- Layout limpo, hierárquico, com bastante respiro
- Headers brancos ou claros com logotipo à esquerda
- Seções alternadas: branco + cinza claro (`#F8FAFC`)
- Imagens de produtos/ícones em SVG ou PNG, sem fundo

### Tom visual
**Corporativo profissional, acessível, orientado a resultados.** Não bold-colorido nem descontraído. Transmite seriedade adequada para um software de gestão fiscal e financeira de varejo.

## O que NÃO fazer
- Não usar paletas saturadas ou neon — fugir ao tom corporativo
- Não sobrecarregar o layout com elementos decorativos (blobs, formas, gradientes intensos)
- Não usar ilustrações lúdicas (cartoon, mascote) — desalinha do público de gestores de farmácia
- Não usar fotos genéricas de stock "happy people" — preferir capturas de tela do produto, ícones representativos ou fotos contextuais de farmácia/varejo
